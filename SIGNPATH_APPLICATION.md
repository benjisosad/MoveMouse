### Description

MoveMouse is an independent MIT-licensed Windows utility that sends continuous relative mouse movement to the right using SendInput. Movement is explicitly started by the user and can be stopped with a global Space hotkey, the Stop button, or by closing the window. It does not install services, inject code, bypass anti-cheat, or access the network. The repository owner describes the intended use as "For Fortnite EXP Farm"; game compatibility and avoiding inactivity checks are not guaranteed, and automation may be restricted by game rules. It is not affiliated with the separate sw3103/movemouse project. Source code and the GitHub Actions build workflow are public. Each signing request would require manual approval.
